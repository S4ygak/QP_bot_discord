# Discord Role Bot
Сделано нейронкой для дальнейшего преобразования и изучения функционала @s4ygak
Простой и удобный бот для выдачи ролей по кнопкам.

## Установка
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте его.
4. Установите зависимости: `pip install -r requirements.txt`
5. Создайте файл `.env` и добавьте туда ваш токен: `DISCORD_BOT_TOKEN=токен_бота`
6. Запустите бота: `python bot.py`

## Использование
Введите `/panel` на сервере, чтобы отправить панель с кнопками.
